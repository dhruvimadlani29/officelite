# Officelite — Responsive Website

A responsive two-page website built with HTML and CSS, 
designed to closely match provided mockups across 
desktop, tablet, and mobile screen sizes.

## 🖥️ Pages
- **Home Page** (`index.html`) — Landing page with navigation and pricing buttons
- **Sign Up Page** (`sign-up.html`) — User registration page

## ✨ Features
- Fully responsive layout using **CSS Flexbox & Grid**
- Mobile-first design across 3 breakpoints (desktop, tablet, mobile)
- Custom CSS properties (variables) for consistent theming
- Linear gradient two-tone background
- Semantic HTML5 markup
- Valid, well-formatted HTML & CSS

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)

## 📐 Design
Mockups provided for desktop, tablet, and mobile views. 
The implementation closely follows the design specifications 
including typography, color palette, and layout structure 
defined in the style guide.
